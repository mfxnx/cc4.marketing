# Templates

Reusable templates for all marketing work at Markit.

## What Goes Here

- Campaign brief templates
- Blog post outlines
- Email sequence frameworks
- Social media post templates
- Competitive analysis frameworks
- Content calendar templates

## Available Templates

| Template | Description |
|----------|-------------|
| `campaign-brief-template.md` | Standard brief format for new campaigns |
| `blog-post-template.md` | Structure for long-form content |
| `email-sequence-template.md` | Framework for multi-email nurture sequences |
| `competitor-analysis-template.md` | Standard format for competitor research |

## Usage

Copy a template to the relevant folder and fill it in — never edit the original template directly.

Example:
```
cp templates/campaign-brief-template.md campaigns/q2-growth/q2-brief.md
```
