## Email Checklist

### Before Writing
- [ ] Clear goal defined (one action per email)
- [ ] Segment identified (who exactly receives this)
- [ ] Fits into the broader sequence or campaign

### Subject Line & Preview
- [ ] Under 50 characters (subject line)
- [ ] No spam trigger words (free!!!, URGENT, Act Now)
- [ ] Preview text adds context — doesn't repeat the subject
- [ ] 3 options written — pick the strongest, A/B test if possible

### Body Copy
- [ ] Opens with the reader's problem, not your product
- [ ] One clear CTA (not three)
- [ ] CTA button text is specific ("Start Free Trial" not "Click Here")
- [ ] Written in plain text style — short paragraphs, no walls of text
- [ ] Personal sign-off (real name, not "The Planerio Team")
- [ ] P.S. line included (most-read line after subject)

### Brand Voice
- [ ] Active voice throughout
- [ ] No jargon or buzzwords
- [ ] Benefit before feature
- [ ] Sounds like a person, not a press release

### Technical
- [ ] Merge tags tested ([First Name] fallback set to "there" or "friend")
- [ ] All links tracked with UTM parameters
- [ ] Unsubscribe link present
- [ ] Tested on mobile
- [ ] Plain text version created
