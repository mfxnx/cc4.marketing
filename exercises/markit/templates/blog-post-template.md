## SEO Checklist

> *Complete before marking the post as ready to publish*

### On-Page SEO
- [ ] Primary keyword in the title (ideally in the first 60 characters)
- [ ] Primary keyword in the first paragraph
- [ ] Primary keyword in at least one H2 heading
- [ ] Primary keyword in the meta title and meta description
- [ ] Primary keyword in the URL slug
- [ ] Secondary keywords used naturally throughout
- [ ] Featured image has descriptive alt text with keyword

### Content Quality
- [ ] Post is at least 1,000 words
- [ ] No paragraph longer than 4 lines
- [ ] Uses H2s and H3s to break up content
- [ ] Includes at least one list, table, or visual element
- [ ] Intro hooks within the first 2 sentences
- [ ] Every section delivers clear value

### Links
- [ ] 2–3 internal links to relevant existing posts
- [ ] 1–2 external links to authoritative sources
- [ ] All links have descriptive anchor text (not "click here")

### Readability
- [ ] Flesch reading score above 60 (aim for plain language)
- [ ] No unexplained jargon
- [ ] Active voice throughout
- [ ] Checked for typos and grammar
