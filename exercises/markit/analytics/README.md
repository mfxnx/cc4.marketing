# Analytics

Performance data and reports for Planerio campaigns.

## Subfolders

- **reports/** — Campaign performance reports, monthly summaries, and channel breakdowns

## What Goes Here

- Campaign performance reports
- Channel-level metrics (email, social, paid ads)
- Trial signup and conversion data
- Monthly and quarterly summaries
- A/B test results

## Key Metrics to Track

| Metric | Target |
|--------|--------|
| Website unique visitors | 20,000 / first 30 days |
| Trial signups | 2,000 / first 90 days |
| Cost per trial signup | < $25 |
| Trial-to-paid conversion | 25% |
| Email open rate | > 35% |

## Naming Convention

`[campaign]-[channel]-report-[date].md`
Example: `q1-launch-email-report-mar2026.md`
